# DeliDev evidence

Keep new records in `issue-<number>/<descriptive-record>.md`. Each record identifies
the source revision, implemented boundary, commands/results and remaining native,
account and platform gaps. Use a different file for an independent validation or
repair; do not append to another issue's record or maintain a shared chronological
index. Directory listings and repository search discover the records.

The original `docs/cmds-delidev-evidence.md` remains a historical ledger with its
original text and anchors. Domain contracts describe current behavior. Evidence
alone does not change a project index, policy or AGENTS file.

`pr-conflict-structure/` records the repository-wide reset requested on 2026-09-30,
including the exact 22-PR closure set and source-preservation inventory.
