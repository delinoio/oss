# Evidence ownership

- Preserve source-backed observations and qualifications. Never turn a fixture,
  build or packaging result into real native/account/platform acceptance.
- Create a separate descriptive record under the owning `issue-<number>/` directory.
  Do not append new runs to the frozen historical ledger or a shared index.
- Record revision, commands, results and unresolved limits. Do not include secrets,
  user state, raw native content or generated binaries.
- The conflict-reset snapshot is an immutable closure allowlist, not a live search.
